# Ars

## Español

**Ars** es una aplicación de museos que relaciona obras de arte con criaturas coleccionables. La idea es mejorar la experiencia de los más jóvenes en los museos y fomentar la vuelta a estos mediante dicha gamificación.
Dicha app se desarrolla con Kotlin Multiplatform y Compose Multiplatform. Las plataformas elegidas son Android y escritorio.

### Cómo probarla

- **Android.** Abre el proyecto en Android Studio y ejecuta `androidApp` en un dispositivo o emulador.
- **Escritorio.** Ejecuta `./gradlew :desktopApp:run` desde la raíz del proyecto.

## English

**Ars** is a museum app that pairs works of art with collectible creatures. The goal is to make museum visits more engaging for younger visitors and encourage them to return through gamification.
The app is being developed with Kotlin Multiplatform and Compose Multiplatform for Android and desktop.

### How to run it

- **Android.** Open the project in Android Studio and run `androidApp` on a device or emulator.
- **Desktop.** Run `./gradlew :desktopApp:run` from the project root.
